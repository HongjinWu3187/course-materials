# 大作业：五级流水线 MIPS 处理器

使用 Verilog 实现五级流水线 MIPS CPU，运行“节点放大器”汇编程序，配套数码管显示、UART 输入输出、仿真与 FPGA 验证资料。

## 从哪里开始

1. 阅读[综合实验要求](01-任务要求/00_综合实验要求_2026夏.pdf)。
2. 查看[最终实验报告](02-最终提交/流水线实验报告_2024010654_吴泓锦.pdf)。
3. 浏览[最终提交源码](02-最终提交/设计代码_含UART功能/)，复现前先读[原提交包中的路径与仿真说明](02-最终提交/【重要】验证前必须改路径_未加后仿文件.txt)。

## 版本与复现说明

- **最终成果以 `02-最终提交` 为准。** 两个开发目录保留了当时的说明，其中“待验证”等记录是历史状态；UART 开发版还包含最终提交包没有附带的辅助脚本。开发版和提交版不应混用。
- 原 Verilog 和 testbench 中存在 `D:/Downloads/...` 绝对路径。综合、实现或仿真前，需要按原验证说明更新 ROM/RAM 初始化文件路径；Vivado 工程中的失效源文件引用也需要重新关联。
- 实际上板综合与实现使用 `BoardTop`。`BoardTop_sim` 用于加速实现后时序仿真，不用于生成实际上板的比特流。
- 原工程文件尚未加入 `tb_board_post_impl.v`、`BoardTop_sim.v` 和 `tb_amplifier_soc_cpi.v`；开展对应验证前，需要手动加入。
- UART 开发版的 `sim/README.md` 提及两个未随原目录提供的仿真 filelist。仓库按原样归档；使用时可在 Vivado 中直接添加所需 RTL 和 testbench。
- 本次整理核对了文件完整性和目录链接，未重新运行 Vivado、RTL 仿真或 FPGA 上板验证。现有报告与截图记录原实验结果。
