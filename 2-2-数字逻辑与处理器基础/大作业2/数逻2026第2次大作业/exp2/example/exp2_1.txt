1. Read Input from test.dat (binary)
   - Read N
   - Read array a[1..N]

2. Initialize DP table
   - Set all dp[i][j] = INF (a large number)
   - dp[1][1] = -1

3. Dynamic Programming (loop version)
   for i = 2 to N:
       for j = 2 to i:
           if a[i-1] < a[i]:
               dp[i][j] = min(dp[i][j], dp[i-1][j-1])
           if dp[i-1][j-1] < a[i]:
               dp[i][i-j+1] = min(dp[i][i-j+1], a[i-1])

4. Check result
   if dp[N][N/2] < INF:
       output 1
   else:
       output 0

5. Print result to screen
