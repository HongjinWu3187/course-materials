# 课程学习资料

这里整理了部分课程作业资料，按学年、学期与课程归档。

## 目录编号

课程文件夹统一采用 **`学年-学期-课程名称`**，沿用原课程目录的编号：

- **第一个数字表示学年**：`1` 为第一学年，`2` 为第二学年，以此类推。
- **第二个数字表示学期**：`1` 为秋季学期，`2` 为春季学期，`3` 为夏季学期。
- 例如，`1-3` 表示第一学年夏季学期，`2-2` 表示第二学年春季学期。

数字逻辑与处理器基础实验的大作业资料中包含夏季学期内容，其课程目录仍沿用原编号 `2-2`。

## 视频与 Git LFS

电子系统课程含 17 个验收视频，约 766 MB。仓库通过 `.gitattributes` 使用 **Git LFS** 管理 `.MOV` / `.mp4` 视频，其他资料保留为普通 Git 文件。

克隆仓库前安装 [Git LFS](https://git-lfs.com/)。克隆后在仓库目录执行：

```bash
git lfs install --local
git lfs pull
```

如果下载后看到的是几行 LFS 指针文本，请用上述命令获取实际视频。GitHub 的 ZIP 下载是否包含视频实体取决于仓库的归档设置，使用 Git LFS 克隆更方便核对完整资料。参见 [GitHub 的 Git LFS 说明](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-git-large-file-storage)。
